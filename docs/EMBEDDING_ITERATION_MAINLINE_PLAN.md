                 |    （失败或再次不一致则退出）
                 |
                 一致
                 |
                 v
       建立并确认 HNSW 索引可用（失败则退出）
                 |

                 |

全量复核只有一个循环，锁下仅比对该次快照记录的源集合/版本。`upgrade_complete` 仅在换表、配置及查询验证事务提交成功后输出；隔离验收不代替第 7 步的完整 CLI/真实模型验收。

## 关键约束

- 迁移目标模型取现有配置，不新增 `--model`；当前 tokenizer 仅支持 BAAI/bge-m3，不支持的目标模型必须在准备/删除下一代表前退出。`--dimension`、`--rpm`、`--tpm` 必填无默认值，维度限 1..=2000，首轮目标 1024。服务中的模型、维度及阈值按本库当前索引配置读取，仅在换表成功时切换。仅当目标模型与维度均等于当前代时拒绝换表，同维度换模型仍需迁移。
- 下一代表不存在则创建；空表、物理维度不同或任一行模型与目标不符则删除重建；仅非空、维度相同且所有行模型与目标一致时保留，按 UUID 升序去重，从已完成记忆中的倒数第二条（包含）恢复，仅一条则从该条开始。模型混合或缺失时不能续跑。以现有下一代表定位，不新增迁移状态表。
- 续跑以整条记忆为单位，事务内替换全部块；不能假定起点前全部成功，结束后仍须全量复核和最多一轮补齐。模型与维度相同只是保留表的条件，不能代替对策略、源版本及完整性的核验。准备和补齐均不得修改当前索引；旧流程的隔离结论不能替代新增恢复规则验收。
- 记忆间串行、块内并发；60 秒窗口按完整输入及每次重试计数，额度不足等待，单次超 TPM 拒发；沿用 5/20/60 秒退避，永久错误不重试。
- 源正文保留原样，每块独立向量；策略包含输入、标题路径、token 预算及 tokenizer 版本。迁移保存策略，`target_generation` 为空；正常刷新仍核验真实目标代号，防止旧任务覆盖新任务。
- 切换时查询模型、维度、阈值和物理表必须匹配；失败保留或恢复旧代，下一次确认其非活动后才能回收。
- 正常回填 worker、额外结构分块规则及本次并发改动对正常刷新入口的重验尚未完成，当前不插入准备命令施工顺序；整体模型请求额度不承诺跨进程协调。

## 执行规则

- 每轮先指向已列出的未完成任务，只交付一个最小验收目标、只改一个职责单一的小函数，逻辑 diff 小于 35 行；代码项实现后勾选并注明待统一验证，停止等待继续。按用户确认先完成剩余开发，期间不逐切片运行行为测试；然后 review 新代码并修复发现，最后统一执行第 7 步，通过后勾选对应主线。
- 按逻辑顺序开发，不预写后续步骤，不扩展未约定的支线。非必要不留持久化测试，临时程序及夹具用后清理。
- 计划只更新状态、关键约束与验收结论，不追加逐轮日志。主线未全部验收不报告整体完成，不提交无关文件；正式环境操作遵守实际授权。
