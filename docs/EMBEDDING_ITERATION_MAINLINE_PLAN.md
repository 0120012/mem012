## 关键约束

- 迁移目标模型取现有配置，不新增 `--model`；当前 tokenizer 仅支持 BAAI/bge-m3，不支持的目标模型必须在准备/删除下一代表前退出。`--dimension`、`--rpm`、`--tpm` 必填无默认值，维度限 1..=2000，首轮目标 1024。普通服务的模型、维度及阈值统一读取 `config.toml`（遵循 `MEM012_CONFIG`）；文件与正式表不匹配，或调用方模型/维度与文件不符时拒绝向量操作。迁移不写文件配置，若显式目标维度不同于文件值，恢复普通向量操作前须同步文件。仅当目标模型与维度均等于当前代时拒绝换表，同维度换模型仍需迁移。
- 下一代表不存在则创建；空表、物理维度不同或任一行模型与目标不符则删除重建；仅非空、维度相同且所有行模型与目标一致时保留，按 UUID 升序去重，从已完成记忆中的倒数第二条（包含）恢复，仅一条则从该条开始。模型混合或缺失时不能续跑。以现有下一代表定位，不新增迁移状态表。
- 续跑以整条记忆为单位，事务内替换全部块；不能假定起点前全部成功，结束后仍须全量复核和最多一轮补齐。模型与维度相同只是保留表的条件，不能代替对策略、源版本及完整性的核验。准备和补齐均不得修改当前索引；旧流程的隔离结论不能替代新增恢复规则验收。

- 源正文保留原样，每块独立向量；策略包含输入、标题路径、token 预算及 tokenizer 版本。迁移保存策略，`target_generation` 为空；正常刷新仍核验真实目标代号，防止旧任务覆盖新任务。
