  +--> 全量复核源集合/版本/块覆盖/模型/维度/策略
  |              |

  |              |          |
  |              |          v
  +--------------|--- 定向补齐一轮，清除停用块
                 |    （失败或再次不一致则退出）
                 |
                 一致
                 |
                 v
       建立并确认 HNSW 索引可用（失败则退出）
                 |
                 v
       按本轮额度生成查询验证向量
                 |
                 v
       NOWAIT 锁定，比对原源集合/版本
                 | （冲突或变化则退出）
                 v

                 |

全量复核只有一个循环，锁下仅比对该次快照记录的源集合/版本。`upgrade_complete` 仅在换表、配置及查询验证事务提交成功后输出；隔离验收不代替第 7 步的完整 CLI/真实模型验收。

## 关键约束

- 迁移目标模型取现有配置，不新增 `--model`；当前 tokenizer 仅支持 BAAI/bge-m3。`--dimension`、`--rpm`、`--tpm` 必填无默认值，维度限 1..=2000，首轮目标 1024。服务中的模型、维度及阈值按本库当前索引配置读取，仅在换表成功时切换。
- 重跑全量重建非活动下一代表，不做跨运行断点续跑，不新增迁移状态表；准备和补齐均不得修改当前索引。既有表未升级，生产环境不能直接套用隔离验收结论。
- 记忆间串行、块内并发；60 秒窗口按完整输入及每次重试计数，额度不足等待，单次超 TPM 拒发；沿用 5/20/60 秒退避，永久错误不重试。
- 源正文保留原样，每块独立向量；策略包含输入、标题路径、token 预算及 tokenizer 版本。迁移保存策略，`target_generation` 为空；正常刷新仍核验真实目标代号，防止旧任务覆盖新任务。
- 切换时查询模型、维度、阈值和物理表必须匹配；失败保留或恢复旧代，下一次确认其非活动后才能回收。
- 正常回填 worker、额外结构分块规则及本次并发改动对正常刷新入口的重验尚未完成，当前不插入准备命令施工顺序；整体模型请求额度不承诺跨进程协调。
