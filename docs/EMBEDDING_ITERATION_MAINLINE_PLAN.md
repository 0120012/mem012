目标事务边界：next 准备及逐记忆块写入分别提交；全量复核、HNSW 建立和切换验证属于整轮迁移事务。后段失败回滚迁移事务，已独立提交的 next 结果保留，正式表维持旧代。全量复核最多补齐一轮，锁下仅比对其源集合/版本快照；仅迁移事务提交成功后输出 `upgrade_complete`。

目标数据库前置结构：不再需要 `memory_embedding_config`；仍要求 `memory_embedding_targets` 等既有表存在，命令不会自动创建它们，缺表会在相应 SQL 执行时退出。普通查询/刷新使用文件配置，配置与正式向量不匹配时拒绝向量读写；调用方保留的模型/维度与文件不一致也在 provider 请求前拒绝，不拼接新旧参数，不借用旧配置表维持服务。

`memory_embedding_targets` 在普通异步刷新中的配合流程：每条记忆至多一行，保存最新登记的生成目标；调用模型前提交登记，写回时再次核验。

```text
    +-- 调用方模型/维度与文件不符 -> 拒绝，重新读取配置后重试
    |
    v

    |

    |  写入 memory_uuid、source_revision、模型、维度和 embedding_policy

    +-- 源状态/版本不符 -> 拒绝登记，不调用模型
    |

    +-- 失败 -> 不写入向量；最新目标登记保留，旧任务仍不能回写

    |
    v

    +-- 表 OID 已变化 -> 拒绝旧代任务写入新表

    |
    v

    |  每块记录 embedding_policy、target_generation=本次 generation
    +-- 失败 -> 回滚本次替换
    |
    v
提交，保留 targets 中该记忆的最新目标登记

同一记忆发生两个任务时：
  任务 A：登记 generation=10 ---- 开始生成 ------------ 完成 -> 拒绝写回
  任务 B：             登记 generation=11 ---- 完成 -> 核验通过后写回
                       |
                       +-- 从此 targets 中的当前代号为 11

批量迁移 prepare-embedding-next：
  不登记 targets -> 块的 target_generation=NULL
  切换阶段锁定 targets + 复核源版本 + 原子换表
  正常刷新中的旧任务即使随后完成，也会因表 OID 改变而被拒绝
```

## 关键约束

- 迁移目标模型取现有配置，不新增 `--model`；当前 tokenizer 仅支持 BAAI/bge-m3，不支持的目标模型必须在准备/删除下一代表前退出。`--dimension`、`--rpm`、`--tpm` 必填无默认值，维度限 1..=2000，首轮目标 1024。普通服务的模型、维度及阈值统一读取 `config.toml`（遵循 `MEM012_CONFIG`）；文件与正式表不匹配，或调用方模型/维度与文件不符时拒绝向量操作。迁移不写文件配置，若显式目标维度不同于文件值，恢复普通向量操作前须同步文件。仅当目标模型与维度均等于当前代时拒绝换表，同维度换模型仍需迁移。
- 下一代表不存在则创建；空表、物理维度不同或任一行模型与目标不符则删除重建；仅非空、维度相同且所有行模型与目标一致时保留，按 UUID 升序去重，从已完成记忆中的倒数第二条（包含）恢复，仅一条则从该条开始。模型混合或缺失时不能续跑。以现有下一代表定位，不新增迁移状态表。
- 续跑以整条记忆为单位，事务内替换全部块；不能假定起点前全部成功，结束后仍须全量复核和最多一轮补齐。模型与维度相同只是保留表的条件，不能代替对策略、源版本及完整性的核验。准备和补齐均不得修改当前索引；旧流程的隔离结论不能替代新增恢复规则验收。
- 记忆间串行、块内并发；60 秒窗口按完整输入及每次重试计数，额度不足等待，单次超 TPM 拒发；沿用 5/20/60 秒退避，永久错误不重试。
- 源正文保留原样，每块独立向量；策略包含输入、标题路径、token 预算及 tokenizer 版本。迁移保存策略，`target_generation` 为空；正常刷新仍核验真实目标代号，防止旧任务覆盖新任务。
- 切换后新正式表的记录模型/维度和物理维度须与本轮目标匹配，并使用本轮目标模型、维度验证余弦查询；阈值来自文件，不随换表保存到数据库。失败保留或恢复旧代，下一次确认其非活动后才能回收。
- 正常回填 worker、额外结构分块规则及本次并发改动对正常刷新入口的重验尚未完成，当前不插入准备命令施工顺序；整体模型请求额度不承诺跨进程协调。
