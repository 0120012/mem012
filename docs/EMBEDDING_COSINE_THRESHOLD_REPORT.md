# 向量召回余弦距离阈值评测结论

**建议将 `BAAI/bge-m3` 1024 维向量召回的距离上限设为 `0.50`。** 该阈值先由 14 条调参查询选出，再在 17 条独立合成查询上验证。相较评测基线 `0.65`，最终精确率从 50.0% 提升到 75.0%，两档均找回全部 15 个相关标注。

`0.47` 在同一批验证查询上补测时少返回 1 条无关结果，最终召回相同。收紧阈值前，应先用一批新的真实查询验证，尤其要覆盖关键词难以命中以及主题相近但库里无答案的情况。

## 余弦距离怎么用

`BAAI/bge-m3` 生成查询和记忆分块的向量。数据库用 `pgvector` 的 `<=>` 计算余弦距离。向量方向越接近，距离越小。阈值 `0.50` 等价于要求余弦相似度至少为 `0.50`。 [向量召回实现](../src/tools/search_memory.rs#L396)

```text
余弦相似度 = (查询向量与分块向量的点积) / (两者长度的乘积)
余弦距离   = 1 - 余弦相似度

二维例子 [3, 4] 与 [5, 0]
点积 = 15，两个向量的长度均为 5
相似度 = 15 / (5 * 5) = 0.60，距离 = 0.40
0.40 <= 0.50，分块通过筛选
```

一条记忆有多个分块时，取最小距离参与筛选和排序，最多保留最近的 40 条记忆。合并后有至少两条候选时，reranker 根据查询和候选原文生成相关性分数。 [候选排序](../src/tools/search_memory.rs#L414) · [搜索流程](../src/tools/search_memory.rs#L125) · [重排实现](../src/tools/search_memory.rs#L472)

```text
查询向量 -> 余弦距离筛选 -> 向量候选 --+
                                       +-> 合并去重 -> 重排 -> 按 limit 截取
查询词   -> 关键词匹配   -> 关键词候选 -+
```

## 评测结果

评测复用两套仓库合成样本。旧样本的 `query` 由 `terms.include` 拼接，新样本沿用原查询。向量阶段使用真实模型和生产分块逻辑，关键词召回、合并与重排在隔离环境中回放。补测设置 `limit: 10`，生产实现当前的返回上限为 8。 [分块样本](embedding_search_samples.json) · [搜索质量样本](search_memory_quality_cases.json) · [生产返回上限](../src/config.rs#L152)

| 余弦距离上限 | 向量阶段召回 | 最终召回 | 最终精确率 | 无答案查询返回结果 |
|---|---:|---:|---:|---:|
| `0.45` | 14/15 | 15/15 | 78.9%（15/19） | 2/4 |
| `0.47` | 15/15 | 15/15 | 78.9%（15/19） | 2/4 |
| `0.50` | 15/15 | 15/15 | 75.0%（15/20） | 2/4 |
| `0.55` | 15/15 | 15/15 | 65.2%（15/23） | 3/4 |
| `0.60` | 15/15 | 15/15 | 51.7%（15/29） | 3/4 |
| `0.65` | 15/15 | 15/15 | 50.0%（15/30） | 2/4 |

`0.45` 漏掉的相关记忆与查询的最小余弦距离约为 `0.4558`，这次由关键词召回补回。`0.45` 和 `0.47` 在 17 条查询上的最终结果及顺序一致。`0.47` 相对 `0.50` 的精确率增益来自少返回 1 条无关记忆，而无答案查询的误召回次数相同。
